## 👋 Hi, I'm taki-0105a

**Building tools for teachers — from the classroom to school operations**

教員として、授業と校務の「ここが面倒」「ここが見えない」を、自分の手で道具にしています。
公開しているのはその一部です。

- 🏫 **校務システム** ― 出欠・進路・成績処理などのデータを一つにつなぐ Web システム
- 🤖 **教員のための AI** ― 授業設計の支援（LLM・RAG）、探究学習の伴走
- 🔒 **ローカルで動く AI** ― 音声入力など、生徒や校内のデータを外に出さない道具
- 📱 **学習アプリと LMS** ― 古文文法の練習アプリ（iOS・Web）、Moodle プラグイン、学習ログの分析
- 🖥️ **Mac の小さな道具** ― 画面共有の作業を楽にするユーティリティ
