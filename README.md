## taki-0105a

Teacher and developer of tools for schools: school information systems, learning apps, Moodle, and xAPI learning analytics.

教員です。授業と校務で必要になった道具を自分で作り、その一部を公開しています。

### 取り組んでいること

- **校務の情報システム**：出欠・進路・成績のデータをつなぐ Web システム（Next.js、Azure、Microsoft 365）
- **学習アプリと LMS**：古文文法の練習アプリ（iOS・Web）、Moodle のプラグイン、xAPI による学習ログの分析
- **教材としての XR**：古典の場面や装束を、ブラウザで立体として見る WebAR・WebVR
- **教員のための AI**：授業設計の支援、探究学習の伴走、端末の中で動く音声入力
